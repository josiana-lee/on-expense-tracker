# 스토어 등록정보 문구

Play Console에 붙여 넣는 문구의 원본이다. 코드가 아니라 스토어에 올라가는 글이라 저장소에
없었다. 바꿀 때는 여기를 먼저 고치고 붙여 넣는다.

수정 위치와 제출 방법은 맨 아래에 있다. 다른 가계부 앱의 이름은 쓰지 않고 파일 형식만 적는다.

## 앱 이름 (11자 / 30자)

온:On 지출 가계부

부제를 붙이는 안("온:On 지출 가계부 - 광고 없는 기록", 22자)도 정책상 허용되고 검토했지만, 이름은
바꾸지 않기로 했다(2026-10-04). 나중에 바꾸고 싶으면 30자 이하, 가격·순위·프로모션·이모지·반복 키워드
없이 쓴다.

## 간단한 설명 (75자 / 80자)

광고·로그인 없는 지출 가계부. 3초 입력, 기록은 내 폰에만. 기존에 쓰던 가계부(CSV·mmbak) 백업 파일도 불러올 수 있어요!

## 자세한 설명 (1396자 / 4000자)

```
광고 없는 지출 가계부, 온:On. 열자마자 입력 화면이 떠서 금액·카테고리·결제수단만 고르면 3초 만에 기록돼요. 회원가입도 로그인도 없고, 모든 가계부 기록은 내 휴대폰에만 저장돼요.

지출 기록만 깔끔하게 정리하고 싶은 분께 맞춘 귀여운 가계부예요.
금액 치고, 카테고리 찍고, 추가. 끝.

■ 3초 입력

· 앱을 열면 바로 입력 화면
· 카테고리 아이콘 한 번 탭이면 세부항목·메모·결제수단까지
· 필요한 카테고리를 직접 골라둘 수 있고, 늘어나면 옆으로 넘겨 봐요
· 방금 넣은 기록은 그 자리에서 바로 고치거나 지울 수 있어요

■ 쓰던 가계부에서 그대로 이어 쓰세요

일부 가계부 앱에서 내보낸 파일을 불러와서, 지난 지출을 이어서 볼 수 있어요.

· 읽을 수 있는 형식 — CSV, SQLite(mmbak), 그리고 이 앱의 백업 파일. 파일을 고르면 형식은 앱이 알아봐요
· 가져오기 전에 건수·기간·지출 합계를 먼저 보여줘요
· 이름이 같은 카테고리는 자동으로 맞추고, 안 맞는 것만 물어봐요
· 카드 할부는 회차를 묶어서 할부로 되살려요
· 잘못 가져왔다면 가져오기마다 골라서 되돌릴 수 있어요
· 같은 파일을 두 번 가져오지 않도록 알려줘요
· 수입은 가져오지 않아요 (지출 가계부예요)
· 지원하지 않는 형식의 파일은 불러올 수 없어요

■ 서버가 없습니다

· 회원가입도, 로그인도, 동기화도 없습니다.
· 모든 기록은 휴대폰 안에만 저장됩니다.
· 지출 내역이 외부로 전송되지 않습니다.
· 백업 파일은 원할 때 직접 만들어 원하는 곳에 보관하세요.

■ 광고가 없습니다
화면을 가리는 배너도, 기다려야 하는 전면 광고도 없습니다.
하지만 언젠가는..

■ 이런 것도 됩니다

· 할부 — 카드로 3개월, 6개월 나눠 결제해도 회차별로 자동으로 달력에 표시돼요
· 달력 — 많이 쓴 날이 색으로 진하게 보이고, 이번 달 지출을 누르면 카테고리별로 쪼개서 볼 수 있어요
· 예산 — 월 예산을 주차별로 쪼개서 보여주고, 넘긴 주는 알려줍니다
· 카테고리별 예산 — 식비만 따로 관리할 수도 있어요
· 자산 — 계좌 잔액과 카드 결제 예정 금액을 한 화면에
· 저장해둔 지출 — 월세, 구독료처럼 자주 쓰는 지출을 이름 붙여 두고 한 탭으로 기록
· 검색 — 메모·항목·카테고리로 지난 기록 찾기
· 백업과 복원 — JSON 백업, CSV 내보내기. 복원하기 전에는 지금 데이터를 앱 안에 자동으로 남겨둬서, 마음에 안 들면 복원 전으로 되돌릴 수 있어요
· 다크 모드 · 색 테마 5종
· 기록 알림 — 매일 정해진 시각에

■ 필요한 권한

· 알림 (선택) — 설정한 시각에 기록 알림
권한을 허용하지 않아도 기록 기능은 모두 사용할 수 있습니다.
백업 파일을 저장하거나 불러올 때는 기기의 파일 선택·공유 화면을 쓰기 때문에 저장소 권한이 필요하지 않아요.
```

## 출시 노트 — versionCode 25

프로덕션은 아직 21이고, 22·23은 내부 테스트에만 나갔다. 24는 빌드만 하고 올리지 않았다(보안 패치를 넣어 25로 다시 뽑음).
23은 방침 고지(11/3) 전이라 따로 올리지 않고 25로 바로 승격하는 것을 기준으로, **프로덕션 노트에는 22·23·25를 합쳐 적었다.** 22를 이미 따로 승격했다면 마지막 두 줄(•)을 뺀다.

**프로덕션 승격용** (324자 / 500자)

```
새로 생긴 기능
• 해외에서 쓴 돈을 외화로 치면 오늘 환율로 계산해 원화가 입력돼요. '해외 결제 금액 입력'에서 USD·EUR·JPY 등 8개 통화를 골라요. 환율은 하루 한 번만 받아오고, 설정에서 끄고 직접 적을 수도 있어요.
• '구독' 카테고리가 생겼어요. 설정 > 카테고리 관리에서 켜면 홈 화면에 보여요. 세부항목도 거기서 추가·수정·삭제해요.
• 신용카드를 고르면 카드 칩이 늘어나면서 그 안에서 일시불·할부를 골라요.
• 메모 칸을 누르면 전에 쓴 메모가 칩으로 떠요.
• 결제일·월 시작일 숫자를 눌러 직접 입력하고, 시작일을 29~31일로도 정할 수 있어요.
```

**23·25 합본 — 22까지 받은 사람 기준** (410자 / 500자)

```
새로 생긴 기능
• 해외에서 쓴 돈을 외화로 치면 오늘 환율로 계산해 원화가 입력돼요. '해외 결제 금액 입력'에서 USD·EUR·JPY 등 8개 통화를 골라요. 환율은 하루 한 번만 받아오고, 설정에서 끄고 직접 적을 수도 있어요.
• 달력의 '+ 추가'에서도 '해외 결제 입력'으로 지난 날짜의 해외 결제를 적을 수 있어요.
• 신용카드를 고르면 카드 칩이 늘어나면서 그 안에서 일시불·할부를 골라요.
• '구독' 카테고리가 생겼어요. 설정 > 카테고리 관리에서 켜면 홈 화면에 보여요.
• 세부항목은 설정 > 카테고리 관리에서 추가·수정·삭제해요. 아이콘도 5개 늘었어요.

고친 것
• 다른 카드로 바꾸면 할부가 일시불로 돌아가요.
• 달력의 '+ 추가'는 열면 현금부터 시작해요.
• 같은 이름의 카테고리는 만들 수 없어요.
```

**내부 테스트 업로드용 — 23 이후 바뀐 것만** (264자 / 500자)

```
새로 생긴 기능
• '구독' 카테고리가 생겼어요(OTT·AI·음악·클라우드). 쓰던 폰에서는 숨겨져 있으니 설정 > 카테고리 관리에서 켜 주세요.
• 카테고리 아이콘이 5개 늘었어요(재생·음악·구름·반짝·게임).
• 세부항목은 설정 > 카테고리 관리에서 추가·이름 바꾸기·삭제해요. 기록하는 화면에서는 고르기만 해요.

고친 것
• 다른 카드로 바꾸면 할부가 일시불로 돌아가요.
• 환율을 받을지 고르기 전에는 숫자판이 잠겨요.
• 같은 이름의 카테고리는 만들 수 없어요.
```

## 수정 위치

- **이름·간단한 설명·자세한 설명:** Play Console > 앱 선택 > 사용자 늘리기 > 앱 정보 > 기본 스토어 등록정보
- **카테고리·태그:** 사용자 늘리기 > 앱 정보 > 스토어 설정 > 앱 카테고리. 2026-10-04에 "생산성"에서 "금융"으로 옮겼다
  (검색 상위 가계부 앱이 전부 금융이었다). 같은 섹션의 "태그 관리"에서 태그를 **최대 5개**, 앱과 가장
  관련 높은 것만 고른다. 앱 페이지에 반영되기까지 최대 24시간. 기능이 크게 바뀔 때만 바꾼다.
- **출시 노트:** 프로덕션 출시 만들기(또는 내부 테스트에서 출시 승격) 화면의 "이 출시 버전의 새로운 기능"

스토어 등록정보 수정도 Play에서는 "제출"이다. 앱에 검토 중인 제출이 있으면 새로 제출하지 않는다
(대기열이 처음으로 돌아간다). 새 번들을 프로덕션으로 승격할 때 문구와 카테고리를 같이 제출한다.
